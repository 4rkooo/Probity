# Probity

Research/demo prototype for grounded video-evidence search and provenance-preserving
reconstruction. **Not for legal conclusions.** See `PROBITY_TECHNICAL_DESIGN.md`.

## Setup

```bash
cp .env.example .env
make setup          # uv sync --frozen (environment in .uvenv; override with UV_ENV=.venv)
make test
```

### Builders Challenge (live VAST / Cosmos / YOLO)

On a workshop VM, map `/config/<team>.config` into `PROBITY_*` and run the API + worker with
live sponsor transports (Cosmos3-Reason + Embed1, VSS/VAST ingress health, YOLO endpoint):

```bash
make setup
uv sync --frozen --extra ui --extra recon
source scripts/workshop_env.sh   # exports PROBITY_* from /config; never prints secrets
make workshop-dev                # or: bash scripts/start_workshop.sh
PROBITY_API_BASE=http://127.0.0.1:8000 streamlit run src/probity/ui/Home.py \
  --server.address 0.0.0.0 --server.port 8501
```

Custom MP4 upload uses the live API. Ingest describes/embeds with NVIDIA Cosmos NIMs and
indexes through the VAST-attributed evidence path. `GET /v1/health` should show
`cosmos-live` and `vast-live` when the workshop stack is reachable.

## Frozen contracts (schema_version 1.0)

| Contract | Location |
|---|---|
| Domain models (frozen, `extra="forbid"`, verified `content_sha256`) | `src/probity/domain/models.py` |
| Enums, job transition table, error-code to HTTP mapping | `src/probity/domain/enums.py` |
| IDs, RFC 3339 time, canonical JSON hashing | `src/probity/domain/ids.py` |
| Protocols and their DTOs | `src/probity/ports.py` |
| HTTP request/response models | `src/probity/domain/api.py` |
| Policy configuration | `config/policy.demo.yaml`, `src/probity/domain/policy.py` |
| Exact Cosmos ingestion prompt | `src/probity/domain/prompts.py` |
| OpenAPI snapshot / JSON Schemas | `contracts/openapi.json`, `contracts/schemas/` |
| Fixture manifest schema / catalog | `fixtures/schema/`, `fixtures/demo/manifest.json` |
| Shared sample fixtures | `fixtures/contracts/*.json`, `fixtures/contracts/artifacts/` |

Build records with `Model.create(**fields)` (fills `schema_version`, `created_at`, and the hash)
and new revisions with `record.revise(**changes)`. `make contracts-check` fails on any drift.
Field changes go through the team interface review.

## Consuming the fixtures (Persons 2 and 3)

All files in `fixtures/contracts/` validate against the frozen models:

```python
import json
from probity.domain.models import ReconstructionRun, JobView
run = ReconstructionRun.model_validate_json(open("fixtures/contracts/reconstruction_run_succeeded.json").read())
jobs = [JobView.model_validate(j) for j in json.load(open("fixtures/contracts/job_views.json"))]
```

- Source clip: `fixtures/demo/source/demo-plate-90s.mp4` (synthetic, regenerated byte-identically by
  `scripts/generate_demo_video.py`). The blue sedan's plate is at `[216,470,292,496)` in frame 417
  (`pts_us=13900000`). The full exact-PTS manifest is in `frame_manifest.json`.
- Tracking: `detections.json`, `track_confirmed.json`, `track_not_confirmed.json`.
- Reconstruction: `reconstruction_run_{succeeded,refused,failed}.json`, `policy_decisions_*.json`,
  `pixel_provenance.json`, `pixel_origin_borrowed.json`. `artifacts/result.png` and
  `artifacts/provenance.npz` (`class`, `source_index`, `source_x`, `source_y`) are **contract
  mocks** (translation copies), not Probity output.
- Review/report: `human_review_{approve,veto}.json`, `evidence_report.json`.
- Jobs: `job_views.json` covers every `JobState` (including PARTIAL, REFUSED, CANCELLED, and
  WORKER_INTERRUPTED and SPONSOR_TIMEOUT failures).
- Search: `search_evidence.json` (prepared query) and `search_evidence_needs_clarification.json`.

Regenerate with `make fixtures` (deterministic IDs and timestamps).
